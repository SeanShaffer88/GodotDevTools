# Godot Android development — knowledge base

A self-contained knowledge base for building Android games and apps
with the Godot engine: the current engine and its support windows,
project anatomy, the Android export pipeline (APK for devices, AAB
for Google Play), languages, plugins, the Play requirements in
force, testing, and CI. Written for AI coding agents first and
human developers second. Every version number and requirement here
was checked against official sources on 2026-11-17 — and this field
moves fast, so [SOURCES.md](SOURCES.md) says where each fact lives
and what to re-check before relying on it.

## TL;DR

Use the current stable Godot (4.7.2) with GDScript unless you have
a reason not to. Export to a device with the pre-built template
(APK); export for Google Play with a **Gradle build** (the only
route to the required AAB). Target API 36, ship from Godot 4.5 or
newer (16 KB page-size support), and commit everything except
`.godot/` and `*.translation` — including `export_presets.cfg`.

## How an AI should use this repo

1. Read [AGENTS.md](AGENTS.md) first — the non-negotiable rules,
   including the version-pinning discipline (Godot's docs are
   versioned, and pages from the wrong version are the single
   biggest source of wrong answers in this field).
2. Read docs in order for a first pass; jump by topic afterwards.
3. Treat every version-sensitive claim as dated. When the repo and
   a live official page disagree, the live page for the *exact
   engine version in use* wins.

## Using this repo with ChatGPT or another AI, locally

This repo is built to be downloaded and used offline by an AI:

1. Download the repo (Code → Download ZIP) and unzip it anywhere.
2. Point the AI at the repo's `knowledge/` folder. It should start with
   [manifest.json](manifest.json) (the file map and reading order)
   and [AGENTS.md](AGENTS.md) (the rules), then read in the manifest's
   order.
3. No time to load a folder? Upload [ai-bundle.md](ai-bundle.md)
   instead — the entire knowledge base concatenated into one markdown
   file. (Generated by [tools/build-ai-bundle.py](tools/); the bundle
   covers the docs and references — templates and tools stay as
   files, listed in the manifest.)

Everything is plain text/markdown with relative links; nothing here
needs a server, an account, or this repository's website.
