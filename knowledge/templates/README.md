# Templates

| File | What it is |
|---|---|
| [`godot.gitignore`](godot.gitignore) | The official Godot 4.1+ ignore list (`.godot/`, `*.translation`) plus the lines a shipped project needs around it: the release keystore and local export outputs. Copy to a new project's root as `.gitignore`. Do **not** add `export_presets.cfg` — it is committed (docs/02). |
| [`project-seed.md`](project-seed.md) | The short list of decisions and files a new Godot Android project starts with, in order. |
