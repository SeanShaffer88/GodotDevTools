# Asset Library submissions

141 per-tool entries generated by `tools/assetlib/generate_assetlib.py`.

The checked-in `zip` fields use legacy local names, not GitHub Release names. Generate tagged metadata as described below when preparing a release.

## Checklist per tool

1. Generate metadata with `--release-tag v1.2.3 --out <directory>`, using the actual release tag. The tag and plugin version need not match.
2. Build the matching archives or verify they exist on the intended GitHub Release; generation does not check whether a release or asset exists.
3. Submit at https://godotengine.org/asset-library/ with the matching JSON fields and actual archive URL.
4. Link the Asset Library page from the tool README.

See docs/ASSETLIB.md.
