# Asset Library submissions

138 per-tool entries generated by `tools/assetlib/generate_assetlib.py`.

## Checklist per tool

1. Build the zip: `zip -qrD GodotDevTools-<tool>-<version>.zip addons/<tool>` (release.yml does this on tags).
2. Submit at https://godotengine.org/asset-library/ with the matching `<tool>.json` fields.
3. Link the Asset Library page from the tool README.

See docs/ASSETLIB.md.
