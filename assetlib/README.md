# Asset Library submissions

141 per-tool entries generated by `tools/assetlib/generate_assetlib.py`.

## Checklist per tool

1. Build a local zip matching the JSON's `zip` field: `zip -qrD GodotDevTools-<tool>-<version>.zip addons/<tool>`. GitHub Release assets use different names and the release tag, not the plugin version; see docs/ASSETLIB.md before using them.
2. Submit at https://godotengine.org/asset-library/ with the matching `<tool>.json` fields and the actual archive URL.
3. Link the Asset Library page from the tool README.

See docs/ASSETLIB.md.
